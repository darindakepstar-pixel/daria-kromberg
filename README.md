# Сайт-портфолио Дарии Кромберг

Статичный сайт: `index.html`, `style.css`, `script.js`, шрифты `*.woff2`, скриншоты работ (`*.webp`).

## Что заполнить
1. **Контакты** — в начале `script.js`, блок `CONFIG`: ник Telegram, почта, ссылка на ВК.
2. **Цены** — в `index.html` замените `от [сумма] ₽` у четырёх услуг.
3. **Фото** — положите своё фото `me.webp` рядом с index.html и в `index.html` замените
   `<div class="about__ph">[ваше фото]</div>` на `<img class="about__ph" src="me.webp" alt="Дария Кромберг">`.
4. **Ссылки на живые сайты** — в `script.js`, в списке `PROJECTS`, поле `url` (пусто = кнопки «Открыть сайт» нет).

## Публикация
GitHub Pages. Если назвать репозиторий `darindakepstar-pixel.github.io`, сайт откроется по короткому адресу без подпапки.
Папку `` загружайте целиком (перетащите папку в окно загрузки) или переименуйте пути на плоские, как в прошлых сайтах.

## Заявки
Форма ничего не хранит на сервере: текст заявки копируется и открывается ваш Telegram, либо открывается письмо на вашу почту.
